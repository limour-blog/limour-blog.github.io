## 准备工作
+ [debian虚拟机](/installing-debian-on-vmware)
+ [axonhub](/replace-one-api-with-axonhub)
+ [chrome](https://www.google.com/chrome/)

## 安装并运行
```bash
conda create -n pi conda-forge::nodejs
conda run -n pi npx @agegr/pi-web@latest --hostname 0.0.0.0
```

## 添加模型和插件
+ 模型格式选择 response 启用缓存
+ 一些好用的插件

```txt
npm:pi-hashline-edit-pro
npm:@juicesharp/rpiv-ask-user-question
npm:pi-rtk-optimizer
npm:pi-agent-browser-native
npm:@ff-labs/pi-fff
```

## 配置插件外部依赖
+ 安装好chrome，并完成初始设置
```bash
conda install -n pi conda-forge::rtk-cli

AGENT_BROWSER_NO_SKILL=1 curl -fsSL https://raw.githubusercontent.com/leeguooooo/chrome-use/main/install.sh | sh
```
+ `nano ~/.local/bin/agent-browser` 写入以下内容
```bash
#!/usr/bin/env sh
exec "$HOME/.local/bin/chrome-use" "$@"
```
+ `chmod +x ~/.local/bin/agent-browser`
