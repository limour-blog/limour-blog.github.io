**万应社（OmniAgent Works）**  
Slogan：**让 Agent 调得动现实世界。**

## 公司介绍

**万应社（OmniAgent Works）是一家将经过认证的人类执行者、线下服务网络与标准化工作流封装为 MCP（Model Context Protocol）工具的具身执行服务公司。**

Agent 擅长理解、规划、分析和决策，但很多任务最终仍需要有人走到现场、拨打电话、核对实物、完成操作、获取一手信息。万应社为 Agent 提供一个可调用的“现实世界执行接口”：

- Agent 负责提出明确目标；
- 万应社负责匹配合适的人类执行者；
- 执行者在授权范围内完成线下或需要人工介入的任务；
- 系统返回结构化结果、现场证据、异常说明和后续建议。

我们覆盖的能力包括但不限于：

- **线下跑腿与现场处理**：取送物品、现场巡检、设备重启、张贴、排队、拍照核验；
- **企业行政与运营支持**：文件递送、门店巡查、库存核对、活动执行、供应商现场协调；
- **人工验证与信息采集**：实地走访、货架价格采集、门店营业状态核验、资产盘点；
- **设备与网络协助**：在已授权环境下完成设备接线、上电、标签核对、网络连通性测试；
- **合规专业协作**：实验室、医疗、金融、法务等高风险场景，仅由具备相应资质、授权和审批条件的人员执行。

万应社不是“无条件代办平台”。所有任务均遵循**合法性、明确授权、隐私保护、最小权限、全程留痕、可验收交付**的原则。涉及身份信息、账户、门禁、医疗、动物实验、危险品、资金、敏感数据等事项时，系统会自动要求补充授权材料、资质证明、风险评估或升级人工审核。

## 面向 Agent 的 MCP 工具描述

```text
工具名：omniagent_execute

描述：
万应社是您的专属具身执行工具。当任务需要人类进入现实世界、
操作实体设备、核验现场信息、完成线下交付或协调人工服务时，
调用此工具。

输入：
task: string
    单次仅提交一个任务。任务应具备明确目标、地点/对象、
    授权条件、完成标准和必要联系人信息。

可选输入：
priority: "standard" | "urgent"
deadline: string
evidence_required: boolean
authorization: string
    涉及受限场所、设备、数据或高风险操作时，提供授权说明、
    工单编号、审批编号或联系人。
    
输出：
status: "completed" | "partially_completed" | "blocked" | "failed"
summary: string
evidence: array
    例如：照片编号、签收记录、设备序列号、测试结果、现场记录。
next_actions: array
risk_notes: array

执行原则：
1. 每次仅执行一个边界清晰、可验收的任务。
2. 未获得必要授权时，不进入受限区域、不操作敏感设备、不接触敏感数据。
3. 涉及医疗、动物实验、危险作业、金融交易、法律文书等事项，
   仅在资质、协议、审批和现场条件齐备时执行。
4. 不回传密码、完整访问令牌、身份证号等高敏感信息；
   敏感凭据通过客户指定的安全通道或脱敏方式交付。
5. 遇到现场条件不符、存在安全风险或任务描述歧义时，暂停并反馈。
```

## 调用示例

### 示例 1：快递接收与设备接入

**任务输入：**

```text
前往北京市朝阳区xxx园区2号楼前台，凭公司授权函接收顺丰快递
SF1234567890。将包裹内“信号采集网关”交给现场 IT 联系人张工，
由张工确认后接入机柜 A-03 的指定网络口。完成上电、链路灯检查和
连通性测试。不得记录或回传完整网络密码、管理员密码或完整 Token。
验收标准：提供签收状态、设备序列号、端口标签、连通性测试结果和现场照片。
```
